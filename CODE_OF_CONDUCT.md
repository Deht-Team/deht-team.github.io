# Code of Conduct

## 1. Purpose
This Code of Conduct exists to keep this project welcoming, friendly, and safe for everyone. Whether you're contributing code, reporting issues, or simply exploring, you deserve a positive environment built on respect and collaboration.

## 2. Our Standards
Everyone participating in this project is expected to follow these principles:

- Be respectful and considerate toward others.
- Use clear, appropriate, and constructive language.
- Keep discussions focused on the project and its goals.
- Offer help and feedback in a supportive way.
- Maintain a safe environment by avoiding harmful or unsafe behaviour.

## 3. Unacceptable Behaviour
The following behaviours are not allowed:

- Harassment, bullying, or targeted negativity.
- Discrimination based on personal characteristics or identity.
- Sharing unsafe, harmful, or inappropriate content.
- Spamming, derailing conversations, or intentionally causing conflict.
- Any behaviour that makes others feel unsafe or unwelcome.

## 4. Reporting Issues
If you experience or witness behaviour that violates this Code of Conduct:

- Contact the project maintainers privately.
- Provide a clear description of what happened.
- Include any relevant context so the issue can be addressed properly.

All reports will be handled respectfully and confidentially.

## 5. Enforcement
Project maintainers are responsible for interpreting and enforcing this Code of Conduct. They may take appropriate action, including:

- Warnings
- Temporary restrictions
- Removal from the project

These actions exist to protect the community and maintain a positive environment.

## 6. Commitment
By participating in this project, you agree to follow this Code of Conduct and help create a safe, welcoming space for everyone.
